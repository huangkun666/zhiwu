# 知悟 (Zhiwu) — 个人 AI 学习与知识内化平台

专为个人深度学习打造的本地全栈学习平台，同时原生适配 **Windows 桌面端** 与 **安卓手机端（PWA）**，所有笔记、错题、闪卡与复习数据完全保存在本地 SQLite 数据库中。

## 核心功能

- **随时导入笔记**：支持 Markdown (`.md`)、纯文本 (`.txt`)、PDF、Word (`.docx`)、批量文件夹导入、快速粘贴，以及**安卓手机直接拍照调用视觉模型 OCR 转文字笔记**。
- **分类与毫秒级全文检索**：支持学科分类目录、多标签管理、置顶及 SQLite FTS5 + 中文子串双引擎全局速搜（`Ctrl + K`）。
- **AI 总结与跨笔记归纳**：单篇笔记一键生成摘要、核心要点、知识脉络与概念词条（同步写入图谱）；支持多选笔记生成横向对比专题归纳报告。
- **动态出题引擎**：基于单篇/多篇笔记、学科分类或薄弱知识点动态出题（单选/多选/判断/简答 AI 批改）。
- **错题集与深度解析**：自动收录错题，支持 AI 根因剖析、个人反思笔记、**一键生成同类变式题**验证举一反三。
- **间隔重复复习与闪卡**：基于 SM-2 艾宾浩斯遗忘曲线统一调度每日到期闪卡与错题；支持从笔记一键制卡与快捷键刷卡。
- **知识图谱与薄弱项诊断**：可视化概念关联网络，实时着色展示各知识点掌握度，一键针对薄弱项专项突破。
- **费曼助教 / 笔记问答**：支持「费曼考官（苏格拉底式追问）」与「深度答疑」双模式。
- **学习数据看板**：近 16 周学习热力图、做题正确率趋势、学科掌握度与连续打卡统计。

## 快速启动

### 方式一：双击一键启动（日常使用推荐）
直接双击项目根目录的 **`启动知悟.bat`**，自动启动单端口服务（`http://localhost:3001`）并打开浏览器。

### 方式二：命令行启动
```bash
# 构建生产版本（单端口同时托管前端与后端，最适合电脑 + 安卓手机同用）
npm run build
npm start

# 或开发调试模式（前端 5173 + 后端 3001 热更新）
npm run dev
```

## 从外部 AI 收录

桌面端更新代码后，运行 `npm --prefix server install` 安装服务端依赖，再运行 `npm run build`。启动知悟，从浏览器复制实际访问的服务地址。将 `zhiwu` 加入 AI 客户端的 MCP 配置，并填入适配器在客户端机器上的完整路径。

```json
{
  "mcpServers": {
    "zhiwu": {
      "command": "node",
      "args": ["<知悟项目的完整路径>/server/mcp.mjs"],
      "env": { "ZHIWU_URL": "<浏览器里实际访问的知悟地址>" }
    }
  }
}
```

接入后，可以直接在对话里说「查看知悟有哪些分类」「建立项目 / 记账小程序 / 设计」「把这段讨论存进这个分类」，也可以用笔记链接指定要追加的笔记。保存后会返回笔记链接，追加内容可在知悟的笔记详情中撤销。

- 文件导入通过 `ZHIWU_IMPORT_DIR` 指定允许收录的本机资料目录。让 AI 传入目录内的文件相对路径，例如 `docs/设计.md`。知悟保留原文件，可以同时指定分类和标签。图片导入后可以直接预览，再按需提取文字。
- 库里存在同路径的重名分类时，先让 AI 列出分类，再用选定的分类编号收录，或在该分类下建立子分类。
- 把 `ZHIWU_ALLOW_READ` 设为 `1` 后，AI 还可以按关键词、分类或标签搜索，并读取选定笔记的正文、提取文本、聊天摘录和原文件地址。
- 跨设备使用时，适配器所在的设备要能访问配置的知悟地址。使用 Bearer 令牌的部署可以另外设置 `ZHIWU_TOKEN`。

## 安卓手机端使用指南

1. 启动服务后，点击页面左下角（或设置页）的 **「安卓手机端扫码访问」**。
2. 保持安卓手机与电脑处于 **同一 Wi-Fi**，用安卓 Chrome / Edge 扫码打开。
3. 在浏览器菜单点击 **「安装应用 / 添加到主屏幕」**，即可生成桌面图标、全屏无地址栏运行，并支持点击「导入 → 拍照 / 选图 OCR」直接拍书本或手写笔记！
4. **出门在外（蜂窝网络）随时访问**：在电脑和安卓手机同时安装免费的 [Tailscale](https://tailscale.com/) 组网，手机直接访问 `http://<电脑TailscaleIP>:3001` 即可安全实时同步。

## 数据安全与备份
- 所有数据存储在 `data/zhiwu.db`，上传的原文件在 `data/uploads/`。
- 可随时在「设置」页一键导出 SQLite 备份文件。
